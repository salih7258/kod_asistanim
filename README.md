# Projenin Adı: Kod-Asistan v0.1
## Projenin Amacı: Kullanıcılara günlük işlerinde (hesaplama, selamlama vb.) yardımcı olacak bir dijital asistan tasarlamak
## Projenin Hedefleri: Bu asistanın ilerleyen zamanlarda hangi özellikleri kazanacağını
* Selamlama v1.0
* Kolay veri girişli dört işlem yapan hesaplama uygulaması v1.1
* Hesaplamaların sonuçlarını ondalıklı gösterebilme v2.0
* Hatalı veri girişini engelleme v2.1
## Projenin kapsamı:
*Girilen iki sayı toplama, çıkarma, çarpma ve bölme işlemi yapabilmek
*Başla
* ''1. sayı:'' gir,a
* ''2. sayı:'' gir,b
* toplam=a+b
* fark=a-b
*çarpım=a*b
* bölüm=a/b
* Yaz'' a+b='',toplam
* Yaz''a-b'',fark
* Yaz''a*b'',çarpım
* Yaz''a/b'', bölüm
* BİTTİ
